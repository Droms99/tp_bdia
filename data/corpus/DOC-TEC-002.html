Manual de configuración del motor de base de datos corporativo

Nivel de confidencialidad: restringido. Contiene parámetros de configuración, criterios de segmentación de red y el esquema de privilegios de las bases que sostienen el núcleo bancario. El acceso se otorga nominalmente a los administradores de base de datos y al responsable de seguridad de la información. Un desarrollador, un analista funcional o el personal de Operaciones no deben acceder a este documento.

1. Alcance

Cubre la configuración de las instancias productivas del motor de base de datos corporativo: los parámetros de memoria y concurrencia, el esquema de privilegios, la configuración de auditoría interna del motor y la política de retención de bitácoras.

2. Principio de mínimo privilegio

Ninguna aplicación se conecta con un rol propietario de objetos. Cada aplicación tiene un rol de conexión sin privilegios de definición de esquema, y los objetos pertenecen a un rol administrativo que no se usa para conectarse. Esta separación es la que permite que las políticas de seguridad a nivel de fila sean efectivas: el propietario de una tabla las ignora salvo que se fuerce explícitamente.

4. Auditoría del motor

Se registra toda conexión, todo cambio de esquema y toda modificación de privilegios. Las bitácoras se envían a un almacén externo al servidor de base de datos dentro de los cinco minutos: una bitácora que vive únicamente en el servidor auditado no sirve como evidencia si ese servidor resulta comprometido.

5. Retención de bitácoras

Las bitácoras de conexión y de cambios de privilegios se conservan por el plazo que fija la normativa de conservación documental. Su eliminación anticipada requiere autorización del Oficial de Seguridad de la Información y queda registrada a su vez.

6. Copias de resguardo

La configuración de copias sigue la política de resguardo y continuidad operativa. El manual solo fija los parámetros técnicos: modo de respaldo, ventana, verificación de restauración y cifrado en reposo del medio de destino.

7. Cambios de configuración

Todo cambio de parámetro en una instancia productiva sigue el circuito de gestión de cambios, con ventana aprobada y plan de retroceso. Un cambio aplicado fuera de ese circuito se considera incidente de seguridad y se trata como tal.
